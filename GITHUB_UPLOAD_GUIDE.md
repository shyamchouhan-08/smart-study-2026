# 🚀 GitHub Pe Upload Kaise Karo — Complete Guide

## Step 1: GitHub Account Banao
👉 https://github.com/signup pe jaao (Free)

---

## Step 2: Naya Repository Banao
1. GitHub pe **"New"** button click karo (green wala)
2. Repository name: `smart-study-assistant`
3. **Public** select karo ✅
4. **"Create repository"** click karo

---

## Step 3: Git Install Karo (agar nahi hai)
👉 https://git-scm.com/download/win se download karo aur install karo

---

## Step 4: Upload Script Chalao
1. Project folder kholo:
   `C:\Users\study\.gemini\antigravity\scratch\smart-study-assistant`
2. **`upload_to_github.bat`** file pe **Right-click** karo
3. **"Run as administrator"** click karo
4. Apna GitHub username daalo
5. Repository naam daalo: `smart-study-assistant`
6. Enter dabao — sab kuch automatic upload ho jayega! ✅

---

## Step 5: GitHub Pages Enable Karo
1. Apni repository kholo GitHub pe
2. **Settings** tab click karo
3. Left mein **"Pages"** click karo
4. Source: **"GitHub Actions"** select karo
5. **Save** click karo

---

## Step 6: Website Live! 🎉
2-3 minute baad website yahan available hogi:
```
https://YOUR-USERNAME.github.io/smart-study-assistant/
```

---

## ⚠️ Important Notes
- Website **Demo Mode** mein chalegi (koi API key nahi chahiye)
- AI features ke liye Settings mein Gemini API key daal sakte ho
- API key milti hai: https://aistudio.google.com/app/apikey (Free)

---
